Put your own Budokai Tenkaichi 4 disc image in this directory.

Supported: BT4 B14 Rev2 (the Team BT4 mod, program SLUS_219.78), LATINO (Spanish) or English, as .iso.
Other versions of the mod are not supported (the port is that program, rebuilt: its checksums are checked).

The first start copies the game's files to ports/dbzbt4/gamedata (about 4 GB) and marks the image as done
(<name>.iso.done); the .iso can then be deleted. A disc of the other language added later installs beside it.

Nothing in this port includes or downloads game data.
