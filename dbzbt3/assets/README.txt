Put your own Dragon Ball Z: Budokai Tenkaichi 3 disc image in this directory.

Supported: the USA release (SLUS-21678) as .iso. A modified image (a translation, Tenkaichi 4
and the like) installs too: what it changes in the game's data is used, what it changes in the
game's program code is not (the port is the original program, rebuilt).

The first start copies the game's files to ports/dbzbt3/gamedata (about 4 GB) and the .iso can
then be deleted. To install another image: delete ports/dbzbt3/gamedata/.installed.

Nothing in this port includes or downloads game data.
