# Legal notice

## No game files included

This project does **not** include any *Dragon Ball Z: Budokai Tenkaichi 3* files, assets, executables or disc
images, and it downloads none. The game must be supplied by the user from a copy they own. The port reads the game's
data from the user's own disc image, on the user's device, and checks that it is the USA release (`SLUS-21678`).
Nothing in this repository or its releases contains or modifies the game's files.

The program is built from the game's decompilation (source code written by the Tenkaichi3Decomp contributors). Its
data tables are shipped empty and are filled at start-up from the user's own disc image.

## Online services

The port does not connect to the network on its own. The online play inherited from the PC version (Dragon Net
Battle, with Tenkaichi3Decomp's matchmaking service) is used only if you start it from the game's menus. It is
untested on handhelds and provided as is.
